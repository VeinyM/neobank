# NeoBank

## О проекте

Здравствуйте!

**NeoBank** — это pet-проект, созданный для демонстрации разработки backend-приложения на Java с использованием экосистемы Spring. Проект имитирует работу простого банковского сервиса и предназначен для практики современных технологий и архитектурных подходов.

На текущий момент реализованы:

* CRUD-операции для основных сущностей;
* Валидация входных данных с использованием DTO;
* Переводы денежных средств между пользователями;
* Логирование транзакций;
* Работа с PostgreSQL;
* Использование Docker для запуска базы данных.

## Используемые технологии

* Java 21
* Spring Boot
* Spring Data JPA
* Hibernate
* PostgreSQL
* Docker
* MapStruct
* Lombok

## Планы по развитию

В ближайших версиях планируется добавить:

* Spring Security;
* JWT-аутентификацию и авторизацию;
* Ролевую модель пользователей;
* Swagger/OpenAPI;
* Более детальную обработку ошибок;
* Unit и Integration тесты.
